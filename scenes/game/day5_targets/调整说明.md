# Day5 零件目标位置

在 Godot 的文件系统中双击对应场景，在 2D 编辑器中调整。

| 场景 | 机器 |
| --- | --- |
| m1.tscn | 风车 |
| m2.tscn | 水泵 |
| m3.tscn | 水车 |
| m4.tscn | 发电机器 |
| m5.tscn | 街灯 |
| m6.tscn | 机械钟 |
| m7.tscn | 传送带 |
| m8.tscn | 通风风机 |

1. 在场景树中选择 `PartTarget1` 到 `PartTarget5`，编号对应工具箱从上到下的五个零件。
2. 拖动零件到正确位置；需要调整大小时，修改检查器里的 `Transform > Scale`。也可以修改 `Position` 和 `Rotation`。
3. 按 `Ctrl+S` 保存，重新运行 Day5。

机器底图已锁定，避免误拖。请保留五个节点的名称以及根节点的元数据。

游戏里的吸附位置、安装后的零件和院子里的修好状态，都会使用这些场景节点。原来的 `day5_part_targets.json` 仅作为历史配置保留，不再决定运行时位置；未使用的修好状态 PNG 已删除。

`create_editable_layouts.py` 是一次性转换脚本；调整后不要重新执行，否则会覆盖手动保存的位置。

每台机器完成后会居中展示完整机器，背后显示旋转光柱。展示同样读取这些零件节点。展示场景为 `scenes/game/day5_repair_showcase.tscn`，根节点的 `Ray Rotation Speed` 控制光柱转速；`fixgame.tscn` 根节点的 `Repaired Preview Seconds` 控制停留时间，默认 2.6 秒。
