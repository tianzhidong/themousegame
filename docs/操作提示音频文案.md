# 森林小镇：操作提示音频文案

编写日期：2026年10月10日。依据当前12关任务配置及已实现的交互逻辑。

配音口吻：温和、清楚、自然，适合儿童；语速稍慢，逗号处短暂停顿。只朗读文案，不朗读任务编号或文件名，不加背景音乐。单击说“点一下左键”，双击说“快速点两下左键”，拖拽说清“按住、移动、松开”。移入任务只提示移动鼠标。

全部137条提示音已使用“生动教学”、语速1.0生成并接入游戏，实际文件为同名WAV，存放于 `assets/audio/voice/task_hints/day01` 至 `day12`。第9关以当前步骤提示为主，整组说明保留在组任务配置中，不与开箱步骤连续重复播放。

第12关8组任务均在滚动主页完成：食物按餐盘图案匹配，行李按车厢图案匹配；树屋双击开窗，水族馆点击动物吐泡泡。滚动只用于浏览地图。树屋和水族馆使用新的提示音文件，旧提示音保留。
